### v3.1 新增（相对 v3）

- **地图**：39 → 50 幅（每幅均为离线示意图 + 多源 Leaflet 实景图，失败自动回退）。新增：五旬节万邦（徒2:9-11）、腓利撒马利亚／迦萨／埃提阿伯太监、扫罗（耶路撒冷→大马士革→阿拉伯→大数）、彼得（吕大–约帕–凯撒利亚）、安提阿与分散（徒11:19）、受审路线（耶路撒冷→凯撒利亚）、船难与风向（革哩底、米利大）、厄纳齐亚大道、亚比亚大道、亚细亚七教会、耶路撒冷圣城平面（圣殿、安东尼堡）。第一次／二次／三次宣教旅行示意图改为编号站点并标注章次。各图附简短历史／文化说明，并嵌入相关章节。
- **动画**：v3 仅有示意图上的 SMIL 圆点；v3.1 新增 7 个可播放／暂停／拖动进度的模块（进展报告柱状图、时间线回放、五旬节外扩、耶路撒冷会议流程、受审流程、船难六幕），并为路线示意图加上 stroke 描绘。动画只用 transform／opacity／stroke-dashoffset，进入视口且滚动停稳后才启动，同时最多播放一个，离开视口即暂停；尊重 `prefers-reduced-motion`。
- **内容加深**：各章要点更锐利；补强难点（徒2:38、8:14-17、19:1-7、徒15 与加拉太 2 的年代、保罗许愿（徒21，原有）、方言、亚拿尼亚与撒非喇（原有）、全家受洗含徒10 圣灵先于洗礼）。新增讲章剖析：彼得徒2、司提反徒7、保罗徒13／17／20／26。目录已纳入新标题。

地图底图可在 OpenStreetMap、Esri 地形／卫星／街道／地貌阴影、OpenTopoMap、OSM Humanitarian、OSM Deutschland 之间切换；某一源失败会自动改换下一个。示意图始终离线可用。Leaflet 自托管，无 CDN。默认使用原生滚动（不再默认加载 Lenis），页面切换使用 CSS View Transitions，悬停预取下一页。
