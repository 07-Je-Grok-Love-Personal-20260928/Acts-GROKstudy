## 🛠️ 构建

```bash
python3 build/build.py      # 生成 docs/
python3 build/verify.py     # 引文校验（联网抓取 CCI）
python3 build/build.py      # 把校验结果写入来源页
python3 tools/qa.py         # playwright + Chrome
```

静态站点位于 `docs/`。在线地图图块需网络；示意图、经文弹层、信条引文与维基共享资源影像副本均可离线阅读。
